MaisonTV es un reproductor IPTV web que funciona íntegramente en tu navegador. No requiere instalación, no usa servidores externos propios y no almacena ningún dato personal. Solo necesitas una lista M3U o M3U8 para empezar a ver canales en streaming.

LISTAS MAISON (1–4)
MaisonTV admite hasta 4 listas M3U simultáneas. Cada lista puede contener miles de canales.

Clic en el nombre (Maison1, Maison2…) — abre el diálogo de carga.
👁 Ojo — activa o desactiva la lista temporalmente. Ámbar = activa, gris = desactivada.
✕ — elimina por completo esa lista y la resetea para cargar una nueva.
CÓMO CARGAR UNA LISTA M3U
🌐 URL — pega la URL de un archivo .m3u remoto. Si hay bloqueo CORS se usan proxies automáticos.
📂 Archivo — selecciona un archivo local. No se sube a ningún servidor.
📋 Pegar texto — pega directamente el contenido de la lista.
💡 Hay listas predefinidas gratuitas disponibles (iptv-org, Free-TV) en el diálogo de carga.

PANTALLAS MÚLTIPLES
MaisonTV puede mostrar 1, 2 o 4 pantallas simultáneas. Usa los iconos de layout en la barra superior.

Clic en un canal para reproducirlo en la pantalla seleccionada (borde ámbar).
Puedes arrastrar y soltar entre pantallas para intercambiar canales.
🔊/🔇 controla el silencio de cada pantalla. ⛶ activa pantalla completa.
BÚSQUEDA Y FILTROS
🔍 Buscar — filtra en tiempo real por nombre o grupo.
Categorías — Noticias, Deportes, Cine, Series… detectadas automáticamente.
★ Favoritos — marca canales con ☆ (aparece al pasar el ratón). Se guardan entre sesiones.
🌍 País — filtra por país de origen detectado automáticamente.
⚠ Errores — muestra solo canales con error de red. Clic derecho para limpiarlos.
CONTROL PARENTAL (+18)
Los canales adultos quedan ocultos por defecto. La primera vez que accedes a +18 el sistema pide crear un PIN de 4 dígitos (guardado como hash SHA-256). El botón +18 en la barra superior permite volver a bloquear el contenido.

TEMA CLARO / OSCURO
Usa el interruptor de la barra superior para cambiar entre tema oscuro y claro. La preferencia se guarda y se restaura al recargar.

REQUISITOS TÉCNICOS
Requiere un navegador moderno con soporte HLS (Chrome, Firefox, Edge, Safari). No se necesita ningún plugin adicional.

⚠ Algunos streams pueden no funcionar por restricciones de la fuente (CORS, DRM, geobloqueo). MaisonTV no controla la disponibilidad de los canales.
